# JavaScript Problem Solving

A collection of programming problem solutions implemented using JavaScript. This repository contains solutions to 20 assigned problems, focusing on problem-solving skills, algorithms, arrays, strings, and basic programming concepts.

## 📌 About This Project

The purpose of this project is to practice JavaScript and improve logical thinking by solving programming challenges.

- **Language:** JavaScript (JS)
- **Total Problems:** 20
- **Solution File:** `solution.js`
- **Testing:** Node.js with built-in assertions

## 📂 Project Structure

```text
problem-solving/
├── solution.js
└── README.md
```
## ⚙️ Requirements

- [Node.js](https://nodejs.org/) installed on your computer
- A code editor such as Visual Studio Code

## 🚀 How to Run

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project folder**

```bash
cd problem-solving
```

**3. Run the solutions and test cases**

```bash
node solution.js
```

If all test cases pass, the terminal will display:

```text
All 20 problem test suites passed!
```

## 🧪 Testing

The `solution.js` file includes test cases for all 20 problems using Node.js's built-in `assert` module.

The test cases cover example inputs, expected outputs, and selected edge cases.
